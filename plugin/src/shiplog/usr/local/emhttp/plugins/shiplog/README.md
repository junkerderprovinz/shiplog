**ShipLog**

Reads the changelog before you update, right inside Unraid's Docker tab. Next to each container ShipLog shows what changes between your running image and the newest one: the release notes, a deterministic risk badge (patch / minor / major) and the real version jump (e.g. 1.7 &rarr; 1.8). A second chip counts the known critical and high vulnerabilities of the running image, sets apart the ones with no fix yet and tells you which of them the update closes.

Updates run through Unraid's own update, by hand or on a schedule limited to the level you choose, with a backup first when your fortress has a backup app. Optional AI changelog summaries from a model server on your own network or through OpenRouter, and messages through Unraid's notifications, a chat or push service, mail or a webhook.
