# The marks of the notification services

`scripts/notify-marks.js` carries one SVG per kind of notification channel. They are copied unchanged from ArrowLoop's generated brand marks (`web/src/components/brandGlyphs.tsx`, built from its `scripts/brand-paths`), apart from JSX turned back into SVG.

## Sources and licences

- **Discord, ntfy, Matrix**: Simple Icons (<https://simpleicons.org>), CC0 1.0.
- **Slack**: Dashboard Icons (`homarr-labs/dashboard-icons`, <https://dashboardicons.com>), `svg/slack.svg`, Apache-2.0.
- **Gotify**: Dashboard Icons, `svg/gotify.svg`, Apache-2.0. The gopher is the Gotify project's own drawing, published under CC BY 4.0 in <https://github.com/gotify/logo>.
- **Unraid**: Dashboard Icons, `svg/unraid.svg` with its gradient left out, Apache-2.0.
- **Healthchecks.io**: `static/img/favicon.svg` from <https://github.com/healthchecks/healthchecks>, the project's own mark.
- **Apprise**: traced from `apprise/assets/themes/default/apprise-logo.png` in <https://github.com/caronc/apprise>, which has no vector of it. The project's own mark.
- **Mail and webhook**: GlimStone's `IconMail` and `IconLink`, nobody's mark.

The Apache-2.0 text of Dashboard Icons is beside this file as `LICENSE-dashboard-icons.txt`. Copyright the Homarr Labs team and contributors. Apache-2.0 is one-way compatible with this project's AGPL-3.0.
